## 문서 간 관계

```
01.new_story.md  ← 원고 정본 (모든 텍스트의 출처)
     │
     ├─→ 02.characters.md    설정을 추출·정리
     │
     ├─→ 04.script-engine.md 엔진 명령어로 변환  ─→ story/*.json
     │
     └─→ 05.continuity.md    구 문서와의 충돌을 기록
                │
                └─→ 03.game-design.md  갱신 지시를 받음
```

---

## 갱신 규칙

1. **원고가 바뀌면** `01`을 고치고, 파생 영향은 `05`에 항목으로 남긴다.
2. **설정이 충돌하면** 임의로 정하지 말고 `05`의 충돌 표에 먼저 올린다.
3. **구버전이 필요해지면** `archive/`에서 읽되, 그곳의 파일은 수정하지 않는다.
4. **작업 기록**은 이 폴더가 아니라 `llm-wiki/log.md`에 남긴다.
