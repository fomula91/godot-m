# 비주얼 노벨 시나리오
## 자리 배정 이벤트 — 선택지 분기 전체

---

> **표기 규칙**
> `[배경]` 장면 전환 · `[BGM]` 배경음악 · `[SE]` 효과음
> `(나레이션)` 내레이션 · `현우 : (속마음)` 내면 독백 · `【선택지】` 분기

---

## 1차 선택지 분기

```
【선택지】
① 취미를 묻는다        → 거리감 대폭 ↑↑  ✅ 기작성
② 반갑게 인사한다      → 거리감 소폭 ↑
③ 친구와 대화한다      → 거리감 대폭 ↓↓
④ 보지 않았다          → 거리감 대폭 ↓↓  (전략 선택지)
```

---

### ② 반갑게 인사한다 (거리감 소폭 ↑)

```
[수아, 새 자리를 확인하고 짐을 챙기는 중이다.]
```

현우 : (말 걸어볼까.)

```
[현우, 수아 쪽으로 걸어간다. 수아는 고개를 숙인 채 가방 지퍼를 잠그고 있다.]
```

현우 :
> 야, 자리 어디야?

```
[수아, 고개를 든다. 현우를 보고 잠깐 굳는다.]
```

수아 :
> ……창가.

현우 :
> 오, 좋은 자리네. 나는 중간이야.

```
[수아, 뭐라고 대답해야 할지 모르는 듯 잠깐 현우를 봤다가 시선을 내린다.]
```

수아 :
> ……그렇구나.

현우 :
> 자리 바뀌고 나서 어때? 불편하진 않아?

수아 :
> ……괜찮아.

```
[짧은 침묵. 수아, 다시 가방을 들고 일어선다. 대화가 끝난 것처럼 보인다.]
```

현우 : (…이게 끝인가. 반응이 너무 짧다.)
현우 : (싫은 건 아닌 것 같은데, 어떻게 이어가야 할지 모르겠다.)

현우 :
> 급식 오늘 뭔지 알아?

수아 :
> ……잡채밥.

현우 :
> 맛있어?

수아 :
> ……별로.

현우 :
> [피식] 그럼 도시락 잘 챙겨왔겠네.

```
[수아, 아주 짧게 현우를 올려다봤다가 다시 시선을 내린다. 대답은 없지만, 표정이 미세하게 부드러워진다.]
```

현우 : (뭔가 반응하긴 했다. 어떤 반응인지는 모르겠지만.)

```
[수아, 조용히 자기 자리로 돌아간다. 현우, 그 뒷모습을 잠깐 본다.]
```

현우 : (…대화를 잘 못 하는 건지, 나랑 하기 싫은 건지.)
현우 : (아직 잘 모르겠다.)

```
[페이드 아웃]
```

> 📌 **분기 결과 :** 어색하게 마무리된다. 수아는 현우를 딱히 경계하진 않지만, 그렇다고 마음을 연 것도 아니다. 거리감 소폭 상승.

---

### ③ 친구와 대화한다 (거리감 대폭 ↓↓)

```
[수아, 새 자리 짐을 정리하고 있다. 현우의 시선이 잠깐 그쪽으로 향하다가—]
```

친구 :
> 야, 자리 나왔다. 어디야?

현우 :
> 나? 중간 쪽.

친구 :
> 나랑 멀리 됐네. 게임할 때 눈빛 교환 못 하겠다.

현우 :
> [웃으며] 수업 시간에 게임 얘기 할 생각은 버려.

친구 :
> 에이, 쉬는 시간에 잠깐씩 하는 거지. 어제 그 판 리뷰 좀 해줘야 하는데.

현우 :
> 아, 그거. 막판 운영이 아쉬웠던 거잖아.

```
[두 사람, 자연스럽게 게임 얘기로 흘러간다. 웃음소리, 손짓.]
```

현우 : (…아, 수아.)

```
[현우, 슬쩍 수아 쪽으로 시선을 던진다. 수아는 조용히 자기 짐을 챙기다가, 현우와 친구를 한 번 바라본다.]
```

현우 : (…보고 있네.)

```
[수아, 현우와 눈이 마주치자 바로 시선을 내린다. 표정이 조금 굳어 있다.]
```

현우 : (…….)

```
[현우, 다시 친구 쪽으로 시선을 돌린다.]
```

현우 : (나중에 말 걸면 되지, 뭐.)

```
[수아, 가방을 들고 조용히 자기 자리로 돌아간다. 현우 쪽은 보지 않는다.]
```

(나레이션)
> 수아는 현우가 웃으며 친구와 대화를 이어가는 모습을 바라봤다.
> 자신과는 다른 세계 사람이라는 걸,
> 그때 다시 한 번 확인한 것처럼.

```
[페이드 아웃]
```

> 📌 **분기 결과 :** 수아는 현우를 '자신과 다른 세계 사람'으로 여기게 된다. 적대감은 없지만 스스로 거리를 둔다. 거리감 대폭 하락.

---

### ④ 보지 않았다 (거리감 대폭 ↓↓ / 전략 선택지)

```
[수아, 새 자리를 확인하고 짐을 챙기고 있다.]
[현우, 자신의 새 자리를 확인한 뒤 친구와 잠깐 이야기를 나눈다. 수아 쪽은 신경 쓰지 않는다.]
```

현우 : (오늘은 별로 할 말이 없기도 하고.)

```
[점심시간. 현우, 급식을 받으러 간다. 수아는 창가에서 도시락을 먹고 있다.]
[현우, 수아 옆을 지나치면서 시선을 주지 않는다.]
```

수아 : (…….)

```
[수아, 현우가 지나친 방향을 잠깐 바라본다. 아무 말도 없다. 표정도 없다.]
[하지만 현우가 다른 친구들 쪽에 앉아 밥을 먹는 것을 한 번 더 본다.]
```

현우 : (오늘 수아 쪽으로 안 갔더니 이상하게 허전하네.)
현우 : (뭐, 매일 같이 먹어야 하는 건 아니니까.)

```
[수아, 도시락통 뚜껑을 닫으며 조용히 창밖을 바라본다.]
```

(나레이션)
> 신경 써주지 않으면, 아쉬워하는 아이.
> 하지만 그걸 현우는 아직 모른다.

```
[페이드 아웃]
```

> 📌 **분기 결과 :** 수아는 아무 말도 하지 않는다. 하지만 거리감은 확실히 벌어진다. 지나치게 거리감이 높아졌을 때 전략적으로 활용 가능한 선택지.

## 2차 선택지 분기
### (1차 ① 취미를 묻는다 선택 이후)

```
【2차 선택지】
① 게임 좋아해?   ✅ 기작성
② 과자 먹을래?
③ 가위바위보!
(거리감 변화 없음 — 분위기 전환용)
```

---

### ② 과자 먹을래?

```
[현우 : (숨기려던 거 맞는데, 물어보니까 다 대답하네. 조심스러운 거지, 싫은 건 아닌가.)]
```

```
[현우, 주머니를 뒤적인다. 과자 하나를 꺼낸다.]
```

현우 :
> 과자 먹을래?

```
[수아, 과자를 바라본다. 잠깐 망설이는 기색이 역력하다.]
```

수아 :
> ……괜찮아.

현우 :
> 사양하지 말고.

```
[현우, 그냥 수아 손에 과자를 쥐어준다.]
[수아, 거절 타이밍을 놓친 채 과자를 들고 있다.]
```

현우 : (받았네.)

```
[현우, 자기도 하나 뜯어 먹으며 딴청을 피운다. 수아는 과자를 들고 잠깐 멍하니 있다가 조심스럽게 하나 먹는다.]
```

현우 : (잘 먹네.)

```
[수아, 현우가 건네주는 대로 계속 받아먹고 있다. 어느새 여러 개째다.]
```

현우 :
> 많이 먹네.

수아 :
> ……어?

```
[수아, 그제야 손 안에 들린 과자 개수를 본다. 눈이 살짝 커진다.]
```

수아 :
> ……켁.

```
[수아, 갑자기 사레가 든다. 콜록콜록.]
[현우, 물티슈를 꺼내 건넨다.]
```

현우 :
> 천천히 먹어.

수아 :
> ……[기침하며] ……거절을 못 해서 계속 먹었어.

현우 :
> [피식 웃으며] 싫으면 됐다고 하면 되잖아.

수아 :
> ……말을 거는 타이밍을 놓쳤어.

현우 : (뭔가 솔직하게 말해줬다.)
현우 : (귀엽긴 하네.)

```
[수아, 물티슈로 입가를 닦으며 시선을 내린다. 살짝 민망한 기색이다.]
```

현우 :
> 다음엔 싫으면 싫다고 해.

수아 :
> ……알겠어.

```
[짧은 침묵. 그런데 수아, 남은 과자를 조심스럽게 하나 더 집는다.]
```

현우 : (……싫은 건 아니었구나.)

```
[페이드 아웃]
```

---

### ③ 가위바위보!

```
[현우 : (숨기려던 거 맞는데, 물어보니까 다 대답하네. 조심스러운 거지, 싫은 건 아닌가.)]
```

```
[현우, 갑자기 손을 내밀며.]
```

현우 :
> 가위바위보!

```
[수아, 순간 반응도 못 하고 굳는다. 그러다 얼떨결에 손을 내밀어버린다.]
```

수아 :
> …………보.

현우 :
> 가위. 내가 이겼다.

수아 :
> ……갑자기 왜.

현우 :
> 심심해서. 딱밤 맞아야 해.

```
[수아, 눈이 살짝 커진다.]
```

수아 :
> ……처음부터 딱밤 내기였어?

현우 :
> 동의했잖아.

수아 :
> ……동의 안 했어.

현우 :
> 얼떨결에라도 냈으면 동의한 거지.

```
[수아, 반박하려다 말문이 막힌다. 현우를 빤히 보다가.]
```

수아 :
> ……진짜로 때려?

현우 :
> 살살.

```
[수아, 이마를 살짝 내민다. 눈을 찡그린 채 현우를 보고 있다.]
```

현우 : (어, 이마 내밀었다. 진짜로 맞을 생각인가.)

```
[현우, 피식 웃으며 아주 약하게 손가락으로 이마를 건드린다.]
```

수아 :
> ……이게 딱밤이야?

현우 :
> 살살 한다고 했잖아.

수아 :
> ……한 번 더 해.

```
[현우, 잠깐 멈춘다.]
```

현우 : (……방금 뭐라고 했지?)

수아 :
> ……이번엔 제대로. 딱밤이 딱밤이지.

현우 : (이 애, 지금 따지는 건가 아니면 즐기는 건가.)

현우 :
> 한 번 더 하려면 한 번 더 해야지.

수아 :
> ……그럼 해.

```
[수아, 다시 손을 내민다. 눈을 찡그리며 기다리는 표정이다. 긴장하는 건지 설레는 건지 모를 표정으로.]
```

현우 :
> 가위바위보!

```
[이번엔 수아가 이긴다.]
```

수아 :
> ……가위. 내가 이겼어.

현우 :
> 바위. 졌네.

```
[수아, 한 박자 쉬다가 아주 조심스럽게 손가락으로 현우 이마를 건드린다. 깃털처럼 가볍게.]
```

현우 :
> 이게 딱밤이야?

수아 :
> ……살살 해도 딱밤이야.

```
[수아, 말하고 나서 살짝 굳는다. 자기가 한 말이 의외로 또렷했던 모양이다. 시선을 내리깐다.]
```

현우 : (……아까보다 분명하게 말했다.)
현우 : (이런 것엔 반응이 있네.)

```
[BGM, 살짝 밝아지며 페이드 아웃]
```

## 분기 요약표

| 선택지 | 거리감 변화 | 핵심 포인트 |
|--------|------------|-------------|
| ① 취미를 묻는다 | 대폭 ↑↑ | 소설을 통해 수아의 내면에 자연스럽게 접근 |
| ② 반갑게 인사한다 | 소폭 ↑ | 어색하게 마무리되지만 적대감은 없음 |
| ③ 친구와 대화한다 | 대폭 ↓↓ | 수아가 스스로 '다른 세계 사람'이라 느끼고 물러남 |
| ④ 보지 않았다 | 대폭 ↓↓ | 무관심에 수아가 아쉬움을 느끼지만 내색 안 함 |
| 2차 ① 게임 좋아해? | 변화 없음 | 수아가 처음으로 먼저 질문함 |
| 2차 ② 과자 먹을래? | 변화 없음 | 거절 못 하고 계속 받아먹는 수아의 귀여운 면모 |
| 2차 ③ 가위바위보! | 변화 없음 | 얼떨결에 시작했지만 수아가 은근히 즐기는 모습 |
