# 05. 설정 연속성 — 충돌·미결 추적

> **상태**: 정본 (2026-08-02 신규)
> **목적**: 새 원고 [01.new_story.md](01.new_story.md)와 기존 기획 문서 사이의 불일치를 한곳에 모아 추적한다.
> **전제**: 2026-08-02 결정 — **게임 구조(허브형 + 거리감 스탯)는 유지하고, 원고만 교체한다.**

작업 중 설정이 충돌하면 이 문서를 먼저 확인한다. 해소된 항목은 표에서 지우지 말고 `해소` 표시 후 결론을 남긴다.

## 1. 원고 ↔ 엔진 레이블 매핑

새 원고는 **화(話) 단위 선형 서술**이고 게임은 **허브형 분기**다. 원고 한 화가 여러 레이블로 분해되거나, 여러 화가 한 이벤트로 묶인다.

| 원고 | 대응 레이블 (04.script-engine.md) | JSON 구현 | 비고 |
|------|-----------------------------------|-----------|------|
| 프롤로그 `#1` | `Start` → `Opening` → `Prologue_Gaze` → `Prologue_Observation` → `Prologue_Awareness` | ✅ 있음 | 원고 갱신분 미반영 (동현 이름, 대사 교체 필요) |
| 1화 (첫 합석) | `Chapter1_Approach` → `Chapter1_Lunch` | ✅ 있음 | 원고 갱신분 미반영 |
| 2화 (자리 바꾸기·소설·게임) | `SeatAssignment` → `SeatAssignment_Hobby` → `SeatAssignment_2nd` → `SeatAssignment_Game` | ❌ 없음 | **원고 2화 = '취미를 묻는다' 루트에 해당.** 나머지 3루트(인사/친구대화/보지않았다)는 원고 미작성 |
| 3화 (수학 시간) | `MathClass` → `MathClass_Teach` → `MathClass_2nd` → `MathClass_Subject` | ❌ 없음 | **원고 3화 = '시간 내서 가르쳐줌' + '잘하는 과목' 루트.** '식 풀이만' / '수포자' 루트 미작성 |
| 4화 (미작성) | `GroupProject` 계열 추정 | ❌ 없음 | 원고 헤더만 존재 |
| 5화 (미작성) | `LunchTime` / `SchoolTrip` 계열 추정 | ❌ 없음 | 원고 헤더만 존재 |
| 6화 (미작성) | 균열 파트 `Crack*` 계열 추정 | ❌ 없음 | 원고 헤더만 존재 |
| — | `DidNotLook`, `CrackIntro`~`CrackBirthday`, `JulyIntro`, `JulyChoice`, `EndingA/B/C`, `GameOver` | ❌ 없음 | 구 `04.script-engine.md`에만 존재. 새 원고 대응분 없음 |

### 여기서 파생되는 구조적 과제

원고가 **메인 루트 한 줄만** 서술하고 있어, 허브 구조가 요구하는 **분기 루트별 원고가 비어 있다.** 예를 들어 자리배정 이벤트는 1차 3택 + 2차 3택 = 최대 9조합이 필요한데 원고에는 1조합만 있다.

→ 선택지별 원고를 어디까지 작성할지 결정이 필요하다. (미결 O-4)

## 3. 미결 사항 (O)

| ID | 항목 | 내용 |

| **O-3** | 2화 선택지 처리 | 원고 675~695줄에 선택지 2택(*"게임은 좋아해?"* / *"어제 저녁에 뭐 먹었어?"*)이 있으나 곧바로 `(이하 통합)`으로 합류한다. **거리감 변동값이 원고에 표기되지 않음.** 03.game-design.md의 거리감 변화표와 연결 필요. |
| **O-4** | 분기 루트별 원고 범위 | 허브 구조는 이벤트당 1차 3택 × 2차 3택을 요구하나 원고는 메인 루트 1줄만 존재. 비(非)메인 루트를 어느 깊이까지 새로 쓸지 결정 필요. |
| **O-5** | 《달빛 아래 우산》 대여 복선 | 2화에서 *"다 읽으면 빌려줄게"* 상태로 보류. 회수 장면이 후속 화에 배치되어야 한다. |
| **O-6** | 현우 스프라이트 | 플레이어 캐릭터의 스프라이트 표시 여부 및 표정 종류가 GDD에서 **[미정]** 상태로 남아 있다. |
