## 자리 배정 이벤트


현우 :
> 어디 됐는데?

> 맨 앞 가운데. 선생님 눈에 바로 띄는 자리잖아.

현우 :
> [피식] 수업 잘 들으면 되잖아.

친구 :
> 야, 진심으로 말하는 거야?

```
[현우, 피식 웃으며 자기 자리를 확인한다. 그러다 시선이 자연스럽게 수아 쪽으로 흘러간다.]
[수아, 새 자리를 확인하며 조용히 가방을 챙기고 있다.]
```

(나레이션)
> 나는 오늘, 수아를…

```
【선택지】
① 취미를 묻는다        → 거리감 대폭 ↑↑
② 반갑게 인사한다      → 거리감 소폭 ↑
③ 친구와 대화한다      → 거리감 대폭 ↓↓
④ 보지 않았다          → 거리감 대폭 ↓↓  (전략 선택지)
```

## 작가 노트

| 포인트 | 내용 |
|--------|------|
| 수아의 반응 설계 | 거절은 없음. 반응이 작지만 분명히 존재함. 2차 선택지에서 처음으로 먼저 질문함 |
| 현우의 독백 톤 | 분석하기보다 일단 행동하고 나중에 의미를 찾는 직감형 |
| 소설 씬 의도 | 수아가 숨기는 것에 현우가 집착하지 않고 자연스럽게 대화로 이어지게끔 |
| BGM 설계 의도 | 수아가 조금씩 열릴 때마다 한 단계 따뜻하게. 마지막 나레이션에서 페이드 아웃 |
| 다음 파트 | 균열 파트 — 수아가 갑자기 피하기 시작 |
