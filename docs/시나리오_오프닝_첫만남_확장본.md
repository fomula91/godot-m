
> 뭐야, 그럼 더 한 의미가 없잖아.

현우 :
> 그러니까.

친구 :
> 오늘 저녁에 또 할 거지?

현우 :
> 당연하지—

## 작가 노트

### 소설 초안 → 스크립트 변환 시 주요 변경점

| 소설 초안 (6차 개정) | 스크립트 반영 |
|---------------------|-------------|
| 프롤로그와 1화가 별도의 날 | **OPENING → 프롤로그(관찰 며칠) → 1화(다가가기)**로 3단계 분리 |
| 현우가 묻지 않고 슬쩍 앉음 | "같이 먹을래?" 대사 삭제. 의자를 끌고 앉는 SE로 대체 |
| "저기, 이수아"로 호칭 | "야, 너" → "저기, 이수아"로 변경 (자연스러운 배려) |
| 수아의 핵심 대사 "여기 있어도 괜찮아?" | "나랑 먹어도 괜찮냐고" → **"여기 있어도 괜찮아?"**로 수정 (자기비하 뉘앙스 강화) |
| 수아의 수락 = 행동 | "알겠어" 대사 삭제 → **젓가락을 다시 집어 드는** 행동으로 전환 |
| 급식 운반 → 매점 | 급식실 쟁반 → **매점에서 삼각김밥 2개 + 우유** (3층↔1층 동선 현실성) |
| 도시락 내용물 묘사 | 하얀색 도시락통, 계란말이·김치·소시지·김가루밥 **클로즈업 연출** 추가 |
| 수아의 식사 동작 | 젓가락 정확히 집기, 한 입씩, 김치 국물 턴기 등 **행동 지문**으로 캐릭터성 전달 |
| 도시락 덮기 + 교실 둘러보기 | 프롤로그 관찰 파트에 **핵심 무언극 장면**으로 배치 |
| "내일도 여기서 먹을 거야?" | 1화 마무리 대사로 배치. 수아의 **끄덕임**으로 응답 |

### 연출 포인트

| 요소 | 설계 의도 |
|------|-----------|
| 프롤로그 시점 제한 | 수아는 **뒷모습만** 등장. 1화에서 처음 정면 스탠딩이 나오며 시점이 확장됨 |
| 수아 스탠딩 등장 타이밍 | "저기, 이수아" 이후 고개를 들 때 — 현우와 동시에 독자도 처음 수아의 얼굴을 봄 |
| 도시락 클로즈업 | 현우가 맞은편에 앉은 뒤 처음 보이는 구도. 반찬의 단출함과 정성이 동시에 전달 |
| SE 설계 | 대화 없는 구간에서 **젓가락 소리·비닐 소리·바람 소리**로 공간감 유지 |
| BGM 감정선 | 프롤로그(잔잔·쓸쓸) → 1화 도입(일상) → 침묵(살짝 작아짐) → 대화 시작(따뜻) → 마무리(어쿠스틱) |
| 수아의 감정 표현 | 입꼬리 미세 변화, 어깨의 힘 빠짐, 눈이 커지는 순간 — 전부 **지문**으로만 처리 |
| "날씨—" 대사 | 현우가 스스로 멈추는 장면. 사교적이지만 깊은 대화에 서투른 캐릭터성 |
