# 사쿠라 학원 - 봄날의 이야기

## 게임 기획서 (Game Design Document)

**프로젝트명**: 사쿠라 학원 - 봄날의 이야기
**장르**: 비주얼 노벨 (Visual Novel)
**플랫폼**: PC (Windows/Mac/Linux), 모바일 (Android/iOS), 웹
**엔진**: Godot 4.6 (GL Compatibility 렌더러)
**해상도**: 1920 x 1080 (16:9)
**예상 플레이 타임**: 약 2~4시간 (1회차 기준)
**타겟 이용 등급**: 전체 이용가

---

## 1. 게임 개요

### 1.1 컨셉

벚꽃이 흩날리는 봄, 전학생인 플레이어가 사쿠라 학원에서 보내는 5일간의 이야기.
두 소녀 **소라**와 **하나**, 그리고 졸업한 선배 **유우**와의 만남을 통해
우정과 사랑, 그리고 자기 자신을 찾아가는 청춘 비주얼 노벨.

### 1.2 핵심 테마

| 테마 | 설명 |
|------|------|
| **봄의 일시성** | "봄은 금방 지나간다" - 소중한 시간은 유한하다 |
| **용기와 인내** | "서두르지 마. 하지만 도망치지도 마" (유우의 메시지) |
| **진심의 가치** | 가면을 벗고 진심으로 마주하는 것의 의미 |
| **함께하는 힘** | "셋이서 함께라면 봄은 끝나지 않아" |

### 1.3 게임의 특징

- **선택지 기반 분기 시스템**: 플레이어의 선택이 호감도와 스토리 진행에 직접 영향
- **호감도 시스템**: 소라/하나 각각의 호감도를 추적하여 엔딩 분기
- **5가지 엔딩**: 소라 트루/노멀, 하나 트루/노멀, 함께 트루 엔딩
- **24개 CG 갤러리**: 주요 이벤트마다 해금되는 이벤트 이미지
- **선택 통계 시스템**: 다른 플레이어들의 선택 비율을 실시간 확인

## 2. 세계관 및 배경

### 2.1 무대

**사쿠라 학원** - 벚꽃으로 유명한 학교. 봄이 되면 교정 전체가 분홍빛으로 물든다.

### 2.2 시간적 배경

신학년도 초반, 벚꽃이 만개한 봄의 1주일 (5일간).

### 2.3 주요 장소

| 장소 | 설명 | 관련 이벤트 |
|------|------|------------|
| **교실** | 일상적인 학교생활의 중심 | 첫 만남, 수업 시간 |
| **도서관** | 소라가 자주 찾는 조용한 공간 | 소라 루트 핵심 장소, 낙서 발견 |
| **옥상** | 하나의 비밀 장소 | 하나 루트 핵심 장소, 비밀 공유 |
| **과학실** | 유우 선배와의 만남 장소 | Day4 유우와의 대화 |
| **강당** | 전시회와 행사 장소 | Day3 전시회, Day5 편지 발견 |
| **수영장** | 석양이 아름다운 비밀 장소 | 하나의 고백 |
| **버스 정류장** | 하교길의 여운 | 석양 장면들 |
| **교정/운동장** | 벚꽃이 흩날리는 공간 | 오프닝, 엔딩 |

## 3. 캐릭터

### 3.1 주인공 (플레이어)

| 항목 | 내용 |
|------|------|
| **이름** | 플레이어 커스텀 입력 (기본: 하루) |
| **신분** | 전학생 |
| **역할** | 소라와 하나 사이의 중재자이자 공감자 |
| **테마 컬러** | 주황색 (#ffa726) |
| **표정** | normal, happy, angry, surprised, worried (5종) |

### 3.2 소라

| 항목 | 내용 |
|------|------|
| **이름** | 소라 |
| **성격** | 조용하고 내향적, 상처가 있지만 따뜻한 내면 |
| **특기** | 독서, 종이학 접기 |
| **단서 아이템** | 종이학 |
| **테마 컬러** | 파란색 (#4a90d9) |
| **표정** | normal, happy, angry, surprised, worried, angry2 (6종) |
| **캐릭터 아크** | 고립 → 경계 → 신뢰 → 개방 |
| **핵심 대사** | "사람과 가까워지는 게 무서웠어요... 달라진 것 같아요" |

**소라의 배경 스토리**:
과거에 혼자 있기를 선호했으며, 아무도 말을 걸어주지 않던 시절이 있었다.
유우 선배가 "같이 밥 먹을래?"라고 처음 물어봐 준 사람이었고,
그 경험이 소라에게 큰 영향을 주었다.
도서관에서 발견한 유우의 낙서가 소라에게 계속 용기를 주고 있다.

### 3.3 하나

| 항목 | 내용 |
|------|------|
| **이름** | 하나 |
| **성격** | 활발하고 밝음, 하지만 내면에 불안감을 숨기고 있음 |
| **특기** | 종이 왕관 만들기, 분위기 메이커 |
| **단서 아이템** | 종이 왕관 |
| **테마 컬러** | 분홍색 (#e87ba1) |
| **표정** | normal, happy, normal2, angry, worried, surprised, yandere, shy (8종) |
| **캐릭터 아크** | 가면 → 균열 → 진심 → 해방 |
| **핵심 대사** | "너 앞에선 굳이 웃지 않아도 될 것 같아" |

**하나의 배경 스토리**:
항상 밝게 웃는 이유는 "웃으면 다들 나를 좋아해줄 거라고 생각했기 때문".
유우 선배가 "가면 벗어도 괜찮아"라고 말해주었고,
그때 처음으로 꾸밈없는 자신을 보여줄 수 있었다.
플레이어 앞에서도 점차 진짜 자신을 보여주게 된다.

### 3.4 유우 (졸업한 선배)

| 항목 | 내용 |
|------|------|
| **이름** | 유우 (게임 내 표시: ???) |
| **성격** | 신비로움, 배려심 깊음, 현명함 |
| **역할** | 멘토, 소라와 하나의 과거를 현재와 연결하는 존재 |
| **테마 컬러** | 보라색 (#9370db) |
| **표정** | normal (기본 1종 + 변형 4종) |
| **핵심 대사** | "서두르지 마. 하지만 도망치지도 마." |

**유우의 역할**:
소라와 하나 모두에게 큰 영향을 준 졸업생.
직접 등장하기 전에도 낙서, 사진 등을 통해 존재감을 보인다.
Day4에서 직접 만나게 되며, 소라와 하나의 과거를 플레이어에게 알려주는 역할을 한다.
Day5 함께 루트에서는 편지를 통해 세 사람에게 메시지를 전한다.

## 4. 스토리 구조

### 4.1 전체 흐름도

```
Day 1: 벚꽃이 피는 아침 (시작 - 첫 만남과 선택)
    ↓
Day 2: 가까워지는 마음 (심화 - 관계 발전)
    ↓
Day 3: 전시회, 그리고... (주요 분기점 - 호감도에 따른 루트 확정)
    ↓
Day 4: 지나간 봄의 기억 (클라이맥스 - 유우 등장, 과거 공개)
    ↓
Day 5: 다시 전하는 마음 (결말 - 고백과 엔딩)
```

### 4.2 Day 1: 벚꽃이 피는 아침

**핵심**: 캐릭터 소개와 첫 번째 선택

| 시간대 | 이벤트 | 선택지 |
|--------|--------|--------|
| 아침 | 벚꽃 아래 미스터리한 인물 목격 (CG: opening-unknown) | - |
| 오전 | 교실에서 소라, 하나와 첫 만남. 칠판 낙서 발견 | 누구에게 물을까? (소라/하나) |
| 오전 | 소라를 도울지 하나를 따를지 | 소라 도움 (+호감도) / 하나 동행 (+호감도) |
| 점심 | 점심시간 행선지 선택 | 도서관-소라 (CG) / 옥상-하나 (CG) |
| 오후 | 구교사 창문의 실루엣 목격 (CG: silhouette) | - |
| 저녁 | 선택에 따른 회상 장면 | - |

### 4.3 Day 2: 가까워지는 마음

**핵심**: 관계 심화와 호감도 축적

| 시간대 | 이벤트 | 선택지 |
|--------|--------|--------|
| 아침 | 호감도에 따른 인사 변화 | - |
| 오전 | 전시회 준비 | 소라와 함께 / 하나와 함께 |
| 오후 | 소라: 종이학 선물 (CG) / 하나: 종이 왕관 선물 | - |
| 저녁 | 소라: 석양 미소 (CG) / 하나: 석양 약속 (CG) | - |

### 4.4 Day 3: 전시회, 그리고... (주요 분기점)

**핵심**: 호감도에 따른 루트 확정

**분기 조건**:
```
소라 호감도 >= 4 AND 하나 호감도 >= 4 → 함께 루트
소라 호감도 > 하나 호감도              → 소라 루트
하나 호감도 > 소라 호감도              → 하나 루트
호감도 동일                           → 함께 루트
```

| 루트 | Day3 엔딩 라벨 | 핵심 이벤트 |
|------|---------------|------------|
| **소라** | "소라: 이름 없는 온기" | 전시회 미술 감상, 벚꽃 아래 교감 |
| **하나** | "하나: 웃음 너머의 진심" | 심리 테스트 부스, 처음 보여주는 진지함 |
| **함께** | "셋: 벚꽃 아래의 약속" | 셋이 함께 전시회, 옥상에서 약속 |

### 4.5 Day 4: 지나간 봄의 기억

**핵심**: 유우 선배 등장, 캐릭터 과거 공개

| 루트 | 핵심 이벤트 | CG |
|------|------------|-----|
| **공통** | 유우 선배와의 만남 (yuu-first-meet) | O |
| **소라** | 도서관에서 과거 이야기, 소라의 눈물 | sora-past-tears |
| **하나** | 강당 뒤편, 가면을 벗은 하나 | hana-unmasked |
| **함께** | 셋이 함께 유우와 식사 | - |

### 4.6 Day 5: 다시 전하는 마음 (엔딩)

**소라 루트**:
- 장소: 도서관, 석양이 비치는 시간
- 소라가 먼저 고백: "당신을 좋아해요. 친구가 아니라... 한 사람으로서."

| 선택지 | 결과 | 엔딩 |
|--------|------|------|
| "기다릴게. 소라의 속도에 맞춰서" | 소라 트루 러브 | **소라 트루 러브 엔딩: 도서관의 석양** |
| "무리하지 않아도 괜찮아요" | 소라 노멀 | **소라 엔딩: 천천히 피는 봄** |

**하나 루트**:
- 장소: 수영장, 석양이 수면에 반사되는 시간
- 하나가 다시 한번 고백: "나는 아직도 너를 좋아해"

| 선택지 | 결과 | 엔딩 |
|--------|------|------|
| "하나의 웃음도, 눈물도, 전부 좋아해" | 하나 트루 러브 | **하나 트루 러브 엔딩: 수영장의 석양** |
| "천천히 가자, 우리" | 하나 노멀 | **하나 엔딩: 새로운 계절의 시작** |

**함께 루트**:
- 장소: 강당 앞
- 유우의 편지 발견 → 셋이 함께 읽으며 감동
- 편지의 핵심: "봄은 끝나지 않아. 너희가 함께라면."

| 엔딩 |
|------|
| **트루 엔딩: 이어지는 봄** |

## 5. 게임 시스템

### 5.1 호감도 시스템

두 히로인(소라, 하나)에 대한 개별 호감도를 추적한다.

| 변수 | 범위 | 영향 |
|------|------|------|
| `sora_affection` | 0 ~ 7+ | 소라 관련 이벤트 해금, 루트 분기 |
| `hana_affection` | 0 ~ 7+ | 하나 관련 이벤트 해금, 루트 분기 |
| `unknown_interest` | 0 ~ 2 | 유우 관련 이벤트 해금 |

**호감도 변화 알림**: 선택 시 화면에 "소라의 마음이 가까워진 것 같다." 등의 힌트가 표시된다.

### 5.2 세이브/로드 시스템

| 항목 | 사양 |
|------|------|
| 세이브 슬롯 | 10개 (수동) + 1개 (퀵 세이브, slot 0) |
| 저장 위치 | `user://saves/slot_{n}.json` |
| 저장 형식 | JSON |
| 저장 내용 | 게임 상태, 스토리 위치, 배경, 캐릭터 배치, BGM, 타임스탬프 |
| 세이브/로드 모드 전환 | 토글 버튼 |

### 5.3 대화 시스템

| 기능 | 설명 |
|------|------|
| **타이핑 애니메이션** | 한 글자씩 나타나는 효과, 속도 조절 가능 |
| **자동 진행** | 설정된 시간 후 자동으로 다음 대사로 진행 |
| **스킵 모드** | Ctrl키로 빠르게 진행 |
| **대화 로그** | 지나간 대사를 다시 확인 가능 |
| **무방해 모드** | UI를 숨기고 배경/캐릭터만 감상 |

### 5.4 선택지 시스템

- 선택지는 2~3개 옵션으로 구성
- 선택에 따라 호감도 변화, 플래그 설정, 라벨 점프가 발생
- **선택 통계**: 특정 주요 선택지에서 다른 플레이어들의 선택 비율을 확인 가능 (Supabase 연동)

### 5.5 갤러리 시스템

| 항목 | 사양 |
|------|------|
| CG 수 | 24개 |
| 해금 조건 | 스토리 진행 중 자동 해금 |
| 저장 위치 | `user://gallery.json` |
| 미해금 표시 | "?" 아이콘 |
| 뷰어 | 전체 화면 CG 감상, 클릭으로 닫기 |

### 5.6 설정 시스템

| 설정 항목 | 기본값 | 범위 |
|----------|--------|------|
| 텍스트 속도 | 20ms/글자 | 슬라이더 |
| 자동 진행 속도 | 5초 | 슬라이더 |
| 음악 음량 | 100% | 0~100% |
| 효과음 음량 | 100% | 0~100% |

## 6. 연출 시스템

### 6.1 배경 전환

| 전환 방식 | 설명 |
|----------|------|
| instant | 즉시 전환 |
| fadeIn | 크로스페이드 (1초) |
| 색상 배경 | `#000000` 등 단색 배경 지원 |

### 6.2 캐릭터 연출

**등장 애니메이션** (5종):

| 효과 | 설명 |
|------|------|
| fadeIn | 서서히 나타남 (0.5초) |
| fadeInUp | 아래에서 위로 올라오며 나타남 |
| slideInLeft | 왼쪽에서 슬라이드 |
| slideInRight | 오른쪽에서 슬라이드 |
| bounceIn | 바운스 효과로 나타남 |

**퇴장 애니메이션** (3종):

| 효과 | 설명 |
|------|------|
| fadeOut | 서서히 사라짐 |
| fadeOutLeft | 왼쪽으로 사라짐 |
| fadeOutRight | 오른쪽으로 사라짐 |

**위치**: 좌측(left), 중앙(center), 우측(right) 3개 슬롯

### 6.3 화면 전환 효과

| 효과 | 설명 |

## 9. 기술 사양

### 9.1 아키텍처

```
┌────────────────────────────────────────────┐
│              입력 레이어 (Input)             │
│  vn_advance (클릭/Enter/Space)              │
│  vn_skip (Ctrl)                            │
└───────────────┬────────────────────────────┘
                ↓
┌────────────────────────────────────────────┐
│           씬 레이어 (Scenes)                │
│  TitleScreen ↔ MainScene ↔ Settings        │
│                    ↕         Gallery        │
│               SaveLoadScreen               │
└───────────────┬────────────────────────────┘
                ↓
┌────────────────────────────────────────────┐
│         싱글턴 레이어 (Autoload)             │
│  StoryManager → 스토리 명령 디스패치          │
│  GameManager  → 상태/세이브/갤러리 관리       │
│  AudioManager → BGM/SFX 재생               │
│  DebugOverlay → 디버그 UI (F3)             │
└───────────────┬────────────────────────────┘
                ↓
┌────────────────────────────────────────────┐
│          데이터 레이어 (Data)                │
│  story/*.json → 17개 스토리 데이터 파일       │
│  user://saves/ → 세이브 파일                │
│  user://settings.json → 설정               │
│  user://gallery.json → 갤러리 해금 데이터    │
└────────────────────────────────────────────┘
```

### 9.2 시그널 기반 이벤트 시스템

StoryManager가 스토리 명령을 파싱하여 시그널을 발행하고,
MainScene이 이를 구독하여 UI를 업데이트하는 옵저버 패턴.

**주요 시그널** (15종):
- dialogue_requested, narration_requested, centered_requested
- choice_requested, scene_change_requested
- character_show_requested, character_hide_requested, character_sprite_changed
- fade_requested, wait_requested, input_requested
- affinity_hint_requested, gallery_unlock_requested
- distraction_free_toggled, end_requested

### 9.3 스토리 데이터 형식 (JSON)

```json
{
  "label": "라벨_이름",
  "script": [
    {"cmd": "show_scene", "id": "classroom_day", "transition": "fadeIn"},
    {"cmd": "show_character", "id": "s", "sprite": "normal", "position": "center", "transition": "fadeIn"},
    {"cmd": "dialogue", "id": "s", "text": "안녕하세요."},
    {"cmd": "choice", "choices": [
      {"text": "선택지 1", "key": "opt1", "target": "Label1"},
      {"text": "선택지 2", "key": "opt2", "target": "Label2"}
    ]},
    {"cmd": "set_var", "path": "sora_affection", "value": 1, "op": "add"},
    {"cmd": "conditional", "branches": [
      {"condition": "sora_affection >= 4", "target": "HighRoute"}
    ], "default": "LowRoute"},
    {"cmd": "gallery_unlock", "id": "opening-unknown"}
  ]
}
```
