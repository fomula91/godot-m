# 0002 — 설정·세이브/로드·백로그는 씬 전환이 아닌 오버레이 모달로 통일

## 상태
채택 (구현됨)

## 맥락
게임 플레이 중 설정·세이브/로드 화면을 열 때, 별도 씬으로 전환하면 메인 씬의 상태(배경·캐릭터·진행 위치)를 저장했다가 복원해야 하고, 돌아올 때 상태 불일치 버그가 생기기 쉬웠다.

## 결정
설정·세이브/로드·백로그를 메인 씬 위에 얹는 오버레이 모달로 통일한다. `main_scene.gd`의 `ModalType` enum(NONE/SETTINGS/SAVE_LOAD/BACKLOG)으로 활성 모달을 단일 상태로 관리하고, 모달 표시 중에는 하부 입력을 차단한다.

## 근거
- 메인 씬이 살아 있으므로 상태 저장/복원 로직 자체가 불필요해짐.
- 단일 enum으로 모달 중복 표시를 구조적으로 방지.
- 대안(씬 전환 + 상태 스냅숏)은 커밋 046defc 이전 방식이었으나 복원 누락 버그가 반복되어 기각.

## 결과·트레이드오프
- 얻는 것: 상태 복원 버그 소멸, 화면 전환 없는 매끄러운 UX.
- 감수하는 것: 모달 씬들이 메인 씬 위에 상주하므로 입력 차단·z-order 관리를 `overlay_controller.gd`에서 정확히 해야 함. 타이틀 화면 등 메인 씬 밖에서 같은 화면을 열 때는 별도 경로 필요.

## 재검토 트리거
모달 종류가 늘어 enum 관리가 번잡해지거나, 모달 위에 모달(중첩)이 필요해지면 스택 기반 모달 매니저로 전환을 검토한다.
